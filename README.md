# MultiverSOM

Site vitrine do projeto **MultiverSOM** — músicas autorais compostas por **Sérgio Melo**, com produção baseada em ferramentas avançadas e minuciosa curadoria.

## 📁 Estrutura

```
multiversom/
├── index.html          ← Página inicial (Home)
├── processo.html       ← O Processo Criativo
├── portfolio.html      ← O Multiverso (Portfólio)
├── compositor.html     ← Sérgio Melo (Sobre)
├── contato.html        ← Faça sua Música (Contato)
├── css/
│   └── style.css       ← Design system completo
├── js/
│   ├── main.js         ← Interações e animações
│   └── components.js   ← Navbar, footer e WhatsApp float
└── assets/
    ├── logo/
    │   └── logomvm.png
    └── images/
        ├── bannermvm.jpg
        └── sergiomvm.jpg
```

## 🚀 Deploy (Hostinger)

| Branch | Ambiente | Pasta na Hostinger |
|--------|----------|--------------------|
| `dev`  | Preview  | `/public_html/multiversom/dev/` |
| `main` | Produção | `/public_html/multiversom/` |

## ⚙️ Formulário de Contato

O formulário em `contato.html` usa [Formspree](https://formspree.io).
Substitua o placeholder na action do form pelo ID gerado no Formspree:

```html
action="https://formspree.io/f/SEU_ID_AQUI"
```
